*A reference document for AI-assisted GM preparation. Upload this to your Claude Project so every conversation is automatically informed by your campaign's specific tone, characters, and history.*

  

# SECTION 1: HOW TO USE THIS DOCUMENT

This bible is designed to sit as a **Project Knowledge** file in Claude.ai. Every conversation you open within the project will have access to it automatically, without any pasting required.

  

**To load it into a Claude Project:**

  

1.  Go to claude.ai → Projects → your campaign project (create one if needed)
2.  Click "Add content" or the Knowledge panel
3.  Upload this .md file directly

  

**When starting a new session**, you can optionally open with a brief context cue like:

  

*"Continuing from last session. \[1–2 sentence summary of where we left off\]. Today I need help with \[task\]."*

  

This isn't required, but it helps orient the AI quickly for session-specific work.
